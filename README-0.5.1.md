# OldЫ Chat 0.5.1 — подготовленные изменения

Статус: исходный код подготовлен, 57 серверных тестов пройдены локально. Сборка APK, проверки на Android и публикация этого выпуска ещё не выполнены. Этот файл не является подтверждением готового обновления.

## Оформление

Единый фон заполняет весь экран, включая области под шапкой, полем ввода и системными панелями. Шапка и поле ввода полупрозрачные, а сообщения сохраняют читаемый фон. Разные оттенки распределены по углам; мягкое свечение можно отключить. Анимация приостанавливается вне экрана и учитывает отключение анимаций и энергосбережение Android.

В «Настройки» → «Обои чатов» можно выбрать один из восьми вариантов или своё фото. Фото заполняет экран с сохранением пропорций; лишняя часть обрезается по центру. Оно сохраняется на телефоне. Кнопка Play расположена точно по центру видеообложки и имеет мягкую неоновую подсветку.

## Контакты

В поиске доступны вкладки «По нику» и «Контакты телефона». Кнопка поиска запрашивает разрешение Android на чтение контактов. Совпадение ищется по подтверждённому e-mail, записанному в контакте; другой участник должен включить возможность находить его. Поиск по телефонному номеру в этом выпуске не реализован: для него сначала нужна проверка принадлежности номера.

Имена и телефонные номера не отправляются на сервер. Для сравнения передаются хеши e-mail, которые всё же можно сопоставить с предполагаемыми адресами. Подробные границы конфиденциальности описаны в SECURITY.md.

## Личный ключ восстановления

В «Защита и резервная копия» добавлено создание личного ключа на телефоне. Сначала сохрани его в менеджере паролей, затем подтверди сохранение защищённой копии. Ключ заменяет пароль текущей облачной копии и нужен для восстановления твоих ключей переписки на другом телефоне после входа по e-mail.

Общего ключа для чтения переписок подписчиков нет. Публикации, комментарии и видео каналов не имеют сквозного шифрования. Протокол личных переписок не проходил независимый аудит и не обеспечивает прямую секретность: компрометация долговременного ключа может раскрыть сохранённую старую переписку.

## Выпуск обновления

Для выпуска нужны подписанный APK версии 0.5.1-beta с versionCode 8 и той же подписью, что у установленной версии, успешные проверки Android и полный серверный архив. Новые маршруты поиска контактов требуют обновить сервер; режим публикации одного APK для этого выпуска недостаточен.

После проверки сборки команда tools/package-console.py должна установить полный выпуск и подтвердить доступность APK через /updates на портах 443 и 8443. Только после этого существующее приложение сможет предложить «Настройки» → «Обновления» → «Обновить». Аккаунт и переписку удалять не требуется. Android запрашивает подтверждение установки.

Установка Яндекс Диска, отправки почты и функции версии 0.5 описаны в README-0.5.md. Новая команда для владельца создаётся непосредственно перед передачей из проверенного артефакта сборки; временную ссылку нельзя хранить в репозитории.
