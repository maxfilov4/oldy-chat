# OldЫ Chat 0.5 — установка и новые функции

Обновление для владельца: вставить команду полного выпуска в консоль сервера, дождаться `OLDY CHAT: UPDATE AVAILABLE 0.5.0-beta`, затем в установленном приложении открыть «Настройки» → «Обновления» → «Обновить». APK скачивается с сервера чата; Android запрашивает подтверждение установки. Аккаунт и переписка сохраняются.

Команда создаётся через `tools/package-console.py` из метаданных проверенного CI-артефакта: HTTPS `url`, `zip_sha256`, `bundle_sha256`. Флаг `--publish-only` исправляет публикацию APK на уже обновлённом сервере без перезапуска и изменений базы. Генератор включает проверку `/updates` на 443 и 8443 и контрольной суммы APK, скачанного с сервера. Временную ссылку передают владельцу непосредственно перед запуском; её нельзя сохранять в репозитории. После первого успешного скачивания команда использует проверенную серверную копию архива.

`Server-maintenance-only.txt` содержит только серверный код и предназначен для обслуживания. Он не публикует APK. Для обновлений внутри приложения требуются `release.json` и `OldyChat-latest.apk` из полного проверенного выпуска. Не выдавать серверную команду как замену полному выпуску.

## Видео в канале

1. Открой свой канал и нажми «＋» → «MP4 в канал».
2. Выбери MP4 до 2 ГБ.
3. В окне «Видео и обложка» выбери нужный кадр ползунком или нажми «Загрузить свою обложку».
4. Проверь превью и нажми «Опубликовать видео».

Горизонтальные ролики получают горизонтальную карточку, вертикальные — вертикальную. Своя картинка обрезается по центру до пропорций ролика. В карточке небольшая кнопка Play внизу; она открывает встроенный плеер.

Справа внизу плеера находится большая кнопка с телефоном: нажатие переводит видео в горизонтальный полноэкранный режим даже при выключенном автоповороте Android. Повторное нажатие возвращает вертикальную ориентацию. Кнопка ⚙ открывает скорость и качество. Качество 480p, 720p или 1080p предлагается только при достаточном исходном разрешении. Сервер готовит отдельный MP4 при первом выборе; это может занять время, особенно для длинного ролика. Исходное видео можно смотреть во время подготовки. Панель управления скрывается во время просмотра и появляется по нажатию на видео.

## Как подключить свой Яндекс Диск

Это настройка владельца сервера, выполняемая один раз. Зрителям канала не нужны аккаунты Яндекса. В ленте и плеере не появляется внешняя ссылка: приложение обращается к серверу чата, который передаёт видео из закрытого хранилища.

1. В своём аккаунте Яндекса открой [создание OAuth-приложения](https://oauth.yandex.ru/client/new). Назови его, например, Oldy Chat Storage.
2. Выбери платформу «Веб-сервисы». Для ручной настройки укажи Redirect URI `https://oauth.yandex.ru/verification_code`.
3. В разрешениях выбери **доступ к папке приложения на Диске** — `cloud_api:disk.app_folder`. Сохрани приложение и скопируй его ClientID.
4. Получи токен по инструкции [Яндекса: доступ к API](https://yandex.com/dev/disk-api/doc/en/concepts/quickstart). Для ручной настройки используй адрес `https://oauth.yandex.ru/authorize?response_type=token&client_id=ТВОЙ_ClientID`, подставив свой ClientID.
5. После установки сервера версии 0.5 открой консоль сервера под root и выполни:

```bash
python3 /opt/oldy-chat/configure-disk.py
```

6. Вставь токен в скрытое поле консоли. Символы при вводе не отображаются — это нормально. Не отправляй токен в чат.

Настройщик создаёт папку `app:/OldyVideos`, загружает небольшой тестовый файл, проверяет чтение его части и удаляет тест. Только после успешной проверки он сохраняет конфигурацию и перезапускает чат.

Теперь добавляй ролики обычным способом внутри канала. Сервер автоматически переносит новые и уже загруженные видео каналов в папку приложения на Диске. Перед удалением локальной копии он проверяет размер и контрольную сумму. При сетевой ошибке сохраняет локальный оригинал и повторяет перенос позже. Обложки и сведения о публикациях остаются на сервере; оригинал может временно понадобиться там для подготовки другого качества.

Для загрузки большого ролика на сервере должно временно хватать места под исходный файл и обработку. Диск экономит постоянное место, но не устраняет серверный трафик. Скорость просмотра зависит от соединения сервера с Диском и от числа зрителей; подключение к реальному Диску и длинный ролик нужно проверить после настройки. Доступ к твоему Диску в этом сеансе не предоставлялся, поэтому реальная загрузка в него ещё не проверена.

Состояние переноса можно посмотреть в консоли:

```bash
journalctl -u oldy-chat --since today
```

`Video storage verified` означает, что копия проверена. `Video storage deferred; local copy retained` означает, что оригинал остался на сервере, а перенос повторится. Если отозвать разрешение Яндекса или изменить OAuth-приложение, настройку нужно выполнить заново. Удаление канала удаляет его видеозаписи из папки приложения; при недоступном Диске удаление завершится после восстановления связи.

## Аккаунт и почта

«Меню» → «Мой профиль»: имя, @идентификатор, постоянный номер аккаунта, аватар, «О себе», почта. Номер выдаёт сервер один раз. Повторные входы и привязка почты не создают новый номер. Для старых аккаунтов номера восстановлены в порядке сохранившихся записей; прежних дат регистрации в базе не было.

В существующем аккаунте выбери «Привязать и подтвердить e-mail». Получи код и введи его в приложении. Имя, ключи и переписка останутся в том же аккаунте. При смене подтверждённой почты старая остаётся действующей до подтверждения новой.

Обычный вход после выхода — по e-mail и одноразовому коду. После закрытия приложения вход сохраняется. На новом телефоне для восстановления зашифрованной переписки дополнительно понадобится пароль резервной копии. Это не повторный пароль обычного входа: он защищает ключи переписки. Для старого аккаунта без привязанной почты есть отдельный вход по прежним данным, чтобы завершить привязку.

Если отправка писем ещё не подключена, на сервере выполни:

```bash
python3 /opt/oldy-chat/configure-mail.py
```

Твой e-mail для входа может совпадать с адресом отправителя. Само совпадение не запрещает отправку письма, но почтовый сервис может по-своему раскладывать такие сообщения. Для службы кодов удобнее отдельный почтовый ящик; пользователю менять личную почту для входа не требуется. Проверь «Входящие», «Все письма» и «Спам».

## Остальные изменения

- Поиск в главном списке обращается к серверу при вводе, находит публичные каналы по словам в названии и по @адресу.
- Удержание чата или канала открывает архивирование и удаление. Архив доступен из меню. Удаление личного чата очищает твою историю, аккаунт собеседника остаётся. Удаление собственного канала удаляет канал для всех и освобождает его @адрес.
- Удерживай микрофон, чтобы записывать голос. Волна показывает фактический уровень микрофона. Отпусти — сообщение отправится. Сдвиг влево заполняет красную шкалу; после её заполнения отпускание удаляет запись. Небольшой сдвиг до порога не отменяет отправку.
- «Настройки» → «Язык / Language»: русский и английский. Переводятся элементы приложения, а не сообщения пользователей.
- Восемь обоев с отчётливыми цветами: игровые, фиолетовые созвездия, бежевый песок, неон, автомобили, лес, закат на трассе и горы. Палитра меняет сам фон в светлой и тёмной теме. Отдельно доступна тема «Киберпанк».
- Смайлы распределены по категориям; видны два ряда с вертикальной прокруткой. Добавлены восемь оригинальных стикеров геймера.
- «Меню» → «Приложения и игры» → «Аудиомастерская»: аудиофайл или запись до двух минут, уменьшение ровного фонового шума, радио, робот, эхо, сравнение и сохранение WAV. Обработка выполняется на телефоне. Сильное шумоподавление может изменять голос; исходный файл сохраняется. Готовый WAV можно добавить в разговор через «＋» → «Аудиофайл».

Прежняя игра про лучи не включена: её исходники или APK не найдены среди доступных проектов. Чтобы перенести именно её, нужен файл игры или исходный проект.
